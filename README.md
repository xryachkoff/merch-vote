# Голосовалка за командный мерч

- Голосование: https://xryachkoff.github.io/merch-vote/
- Админка: https://xryachkoff.github.io/merch-vote/admin.html

Статическая страница на GitHub Pages и бэкенд на Google Apps Script. Голоса и комментарии пишутся на вкладки `votes` и `comments` таблицы «Идеи для командного мерча».

## Как устроено
- **Голосование** (`index.html`). Человек один раз вводит имя. Браузер получает случайный ID, который хранится в localStorage. Можно выбрать максимум 2 варианта и поменять голос, пока голосование открыто. Комментарий оставляется к любому варианту.
- **Админка** (`admin.html`). Вход по паролю, его проверяет сервер. Внутри: рейтинг, таблица «кто за что голосовал», все комментарии, выгрузка CSV и кнопка «закрыть / открыть голосование». Если одно имя голосовало с разных устройств, строка помечается «дубль?».
- **Варианты** (`variants.json`, `images/`). 15 уникальных картинок из таблицы, 2 точных повтора убраны.
- **Бэкенд** (`apps-script/Code.gs`). Лимит в 2 голоса и закрытие голосования проверяются на сервере. После 10 неверных паролей админка блокируется на 10 минут.

Ограничение: без входа через аккаунт голос привязан к браузеру. Повторно проголосовать из другого браузера или из инкогнито можно, но в админке это видно как «дубль?», если человек ввёл то же имя.

## Запуск (один раз)
1. Откройте таблицу и выберите Расширения → Apps Script.
2. Вставьте туда содержимое `apps-script/Code.gs`. В `ADMIN_PASSWORD` впишите пароль админки. В репозиторий пароль не коммитьте.
3. Нажмите Deploy → New deployment → тип **Web app**. Execute as: **Me**, Who has access: **Anyone**. Разрешите доступ.
4. Вставьте полученный URL (`https://script.google.com/macros/s/…/exec`) в `APPS_SCRIPT_URL` в `config.js`, закоммитьте и запушьте.

Если потом правите `Code.gs`, выбирайте Deploy → Manage deployments → Edit → **New version**. Тогда URL не поменяется.

## Релиз изменений фронта
Поднимите `VERSION` в `config.js` и `?v=` в ссылках на `config.js`, `app.js` и `style.css` в обоих HTML-файлах. GitHub Pages разрешает браузерам кэшировать файлы 10 минут, и без новой версии люди получат смесь старых и новых файлов.
